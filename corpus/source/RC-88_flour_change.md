## 1. Change description

This recipe change records the change described below.

| Field | Entry |
| --- | --- |
| Recipe change | RC-88 |
| Subject | Flour, Classic Sourdough (SD-12) |
| Raised | 2024-09-11 |
| Category | Class A |
| Originating function | Recipe Change Board |
| Status | Implemented |

The flour specified for the Classic Sourdough (SD-12) is revised to Heritage
Stoneground flour. The revision applies to every batch of the product mixed
from the date this change was raised.

The change is limited to the flour. No other ingredient is altered and no
other product in the range is affected.

## 2. Affected products

| Product | Product code | Affected |
| --- | --- | --- |
| Classic Sourdough | SD-12 | Yes |
| Country Sourdough | SD-13 | No |

Stock of the product mixed before the date this change was raised may be sold
through.
