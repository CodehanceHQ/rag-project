## 1. Return volumes

This summary records units returned from the field in the second half of 2024,
by month and by receiving route. Volumes are stated as units received and
booked in; units in transit at the period end are carried into the following
period.

| Month | Units returned | Booked in |
| --- | --- | --- |
| July | 41 | 41 |
| August | 38 | 38 |
| September | 52 | 50 |
| October | 61 | 61 |
| November | 58 | 57 |
| December | 44 | 40 |

Return volumes across the period are within the range recorded for the
preceding period. No return was refused on receipt.

## 2. Findings by symptom

Each returned unit is assessed on receipt and a symptom recorded against it.
Symptoms are recorded as observed, without assessment of origin. Where more
than one symptom is present, each is recorded.

| Symptom | Units | Share |
| --- | --- | --- |
| Fasteners found backing off at the housing interface | 96 | 31% |
| Seepage at the seal interface | 74 | 24% |
| External damage in handling | 58 | 19% |
| Incorrect configuration supplied | 41 | 13% |
| No fault found on assessment | 40 | 13% |

Fasteners found backing off at the housing interface is the most frequently
recorded symptom for the period. In each case the fastener remained engaged
and no fastener was recovered detached.

Measured residual torque on units recording this symptom fell below the
specified value in every case assessed. The measured spread is recorded in the
assessment sheets held with the individual return records.

| Residual torque on assessment | Units |
| --- | --- |
| Within specified value | 0 |
| Below specified value, within 20% | 34 |
| Below specified value, beyond 20% | 62 |

Units recording seepage at the seal interface were assessed separately and are
reported under the certification correspondence for that characteristic.

## 3. Parts disposition

Returned units are dispositioned on completion of assessment.

| Disposition | Units |
| --- | --- |
| Rework and return to stock | 187 |
| Scrap | 63 |
| Return to customer, no fault found | 40 |
| Held pending assessment | 19 |

Units held pending assessment at the period end are carried forward. The
disposition record for each unit is held with the individual return record.
