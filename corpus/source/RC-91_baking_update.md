## 1. Change description

This recipe change records the change described below.

| Field | Entry |
| --- | --- |
| Recipe change | RC-91 |
| Subject | Baking procedure, Classic Sourdough (SD-12) |
| Raised | 2025-06-16 |
| Category | Class C |
| Originating function | Recipe Change Board |
| Status | Implemented |

The baking procedure for the Classic Sourdough (SD-12) is changed. Steam is
now used for the first 10 minutes of the bake, and the core temperature of the
loaf is now checked after 35 minutes.

The oven temperature is not changed. The change is carried into the baking
instruction at Revision D.
