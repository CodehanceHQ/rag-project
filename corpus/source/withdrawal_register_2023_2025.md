## 1. Register of withdrawals 2023–2025

The register lists every product withdrawal raised in the period, one row per
withdrawal. Detail is held in the report for each withdrawal and is not
repeated here.

| Withdrawal | Raised | Product | Type |
| --- | --- | --- | --- |
| W-2023-006 | 2023-03 | Seeded batch loaf | Labelling |
| W-2023-019 | 2023-09 | Fruit scone | Date coding |
| W-2024-003 | 2024-01 | Almond croissant | Labelling |
| W-2024-011 | 2024-06 | Cheese straw | Packaging |
| W-2024-022 | 2024-11 | Mince pie | Date coding |
| W-2025-014 | 2025-02 | Classic Sourdough (SD-12) | Withdrawal from sale |

A withdrawal is entered in the register on the day it is raised.

## 2. Closure status

A withdrawal is closed when its report has been signed off by Food Safety.

| Withdrawal | Status |
| --- | --- |
| W-2023-006 | Closed |
| W-2023-019 | Closed |
| W-2024-003 | Closed |
| W-2024-011 | Closed |
| W-2024-022 | Closed |
| W-2025-014 | Open |

The register is reissued whenever a status changes.
