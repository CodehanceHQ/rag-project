## 1. Basis

Certification approval for the assembly family is held against the
configuration recorded in the approved technical file. Where a characteristic
recorded in that file is altered, the approval is held against the superseded
configuration until the altered configuration is evidenced.

The seal material recorded against the housing interface has been altered to
FKM-70. The interface is a certified characteristic. Accordingly,
**revalidation required following the material change** before the altered
configuration may be evidenced against the existing approval.

| Field | Entry |
| --- | --- |
| Requirement reference | CERT-RQ-2024-31 |
| Raised | 2024-11-08 |
| Trigger | Alteration to a certified characteristic |
| Approval affected | Assembly family, seal interface |
| Status | Scheduled |

Until the requirement is discharged, the approved technical file continues to
record the superseded configuration and the certification position is
unchanged.

## 2. Scope of revalidation

The revalidation comprises the interface test sequence defined in the approved
test plan, performed on the altered configuration and witnessed in accordance
with the witnessing arrangement.

| Element | Requirement |
| --- | --- |
| Interface test sequence | Full sequence, altered configuration |
| Thermal cycling | Per approved test plan |
| Witnessing | Per witnessing arrangement |
| Report | Submitted to the approval holder |
| Status at issue of this notice | Scheduled, not yet performed |

Partial revalidation is not accepted for an alteration to a certified
characteristic. The sequence is to be performed in full.

The requirement remains against the approval until the report is submitted and
accepted. Rig availability for the sequence is arranged through the test
laboratory under the usual booking arrangement.
