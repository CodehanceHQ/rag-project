## 1. Action

Corrective and preventive action logged against the field safety action
recorded under reference R-2025-014.

| Field | Entry |
| --- | --- |
| Record | CAPA-2025-019 |
| Logged | 2025-04-02 |
| Action reference | R-2025-014 |
| Action | Revise the seal interface qualification test sequence |
| Owner | Quality Management System |

The action requires the qualification test sequence for the seal interface to
be revised to include sustained thermal cycling at the upper end of the
declared operating range, and the revised sequence to be adopted into the
approved test plan.

## 2. Status

Progress against the action is reviewed monthly and recorded below. The entry
at the most recent review is the current position.

| Review | Position |
| --- | --- |
| 2025-07 | Draft sequence prepared |
| 2025-10 | Draft sequence under technical review |
| 2026-01 | Technical review comments being addressed |
| 2026-03 | In progress |

The action is in progress. Adoption into the approved test plan follows
completion of the technical review and is not yet scheduled.
