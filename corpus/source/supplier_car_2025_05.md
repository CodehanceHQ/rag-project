## 1. Request

Corrective action requested of the supplying source following a nonconforming
delivery received at Plant X (Bamberg).

| Field | Entry |
| --- | --- |
| Request | CAR-2025-007 |
| Raised | 2025-05-14 |
| Receiving site | Plant X (Bamberg) |
| Delivery reference | DN-2025-1188 |
| Nonconforming characteristic | Seal hardness below specification |

The delivery was sampled at incoming inspection and rejected. A corrective
action response is required within the interval stated in the supply
agreement.

## 2. Supplier response

The supplying source responded within the stated interval. The response is
summarised below and is held in full with this request.

| Element | Response |
| --- | --- |
| Containment | Affected lot quarantined at source |
| Immediate action | Process parameters reset to nominal |
| Verification at source | Sample of 60 assessed, conforming |
| Response date | 2025-05-28 |

The source attributed the condition to a process parameter drift at the
moulding stage and stated that the parameter had been reset and the affected
lot contained.

## 3. Verification

Verification was performed on the next two deliveries received at the site
following the response.

| Delivery | Sampled | Result |
| --- | --- | --- |
| DN-2025-1256 | 30 | Conforming |
| DN-2025-1301 | 30 | Conforming |

The request is closed on the basis of the verification above. Closure applies
to this request only.
