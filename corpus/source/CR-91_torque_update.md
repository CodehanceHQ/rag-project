## 1. Change description

This change request records a revision to the tightening procedure specified
at the housing interface of the assembly identified in section 2.

The procedure is amended to require a defined tightening sequence and a
recheck at a stated interval after initial tightening. The specified torque
value is unchanged by this request.

| Field | Entry |
| --- | --- |
| Change request | CR-91 |
| Raised | 2025-06-17 |
| Category | Process change |
| Originating function | Engineering Change Board |
| Status | Implemented |

No change is made to the fastener specification, the fastener finish, the
housing interface dimensions or the seal specification. Tooling is unaffected.
The calibration interval for the torque wrench is unchanged.

## 2. Affected documents

This change applies to the following controlled documents.

| Document | Action |
| --- | --- |
| WI-BV12 | Reissue at Revision D |
| WI-BV12 Revision C | Withdraw and supersede |

Withdrawal of the superseded revision is to be completed at all workstations
before the reissued revision is worked to. Manufacturing Engineering is to
confirm withdrawal against each workstation.

No other assembly in the series is affected by this request. Assemblies
carrying a different fastener dimension are specified under their own
instruction and are outside the scope of this change.
